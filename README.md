# WEBNOVA IA

Plataforma de prospecção comercial para encontrar, organizar e qualificar leads de empresas. O projeto reúne uma landing page comercial, autenticação inicial e um dashboard responsivo preparado para receber integrações reais de busca de leads, listas, relatórios, planos e automações de prospecção.

## Stack

- React + TypeScript
- TanStack Start / TanStack Router
- Vite
- Tailwind CSS v4
- Lucide React

## Estrutura atual

- / — landing page da WEBNOVA IA
- /login — tela de acesso
- /dashboard — painel central e módulos da plataforma

## Status

A interface principal está estruturada como produto SaaS. A autenticação, fonte real de leads, pagamentos e automações externas ainda serão conectados nas próximas etapas.
